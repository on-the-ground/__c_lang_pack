# Subsea Cable authoring context

For tasks that write, explain or review `.vyg` source, read `SKILL.md` and
`knowledge/model.md`, then only the modules needed for the task. Read
`knowledge/few-shot.md` when a concrete example would help. Treat this knowledge
as authoring guidance, not evidence that a program validates or ran.

For maintenance, follow `docs/MAINTAINING.md`. Keep the pack in this repository;
never add its modules, builders or archives to the language repository.
